# Fluffy Forest — Animal Sort

**An original casual browser puzzle by [Black Orange Agency](https://blackorange.agency/)** — the team working across growth marketing, AI-powered business products, dashboards and games.

Arrange matching forest animals on branches to reunite the families. Designed for short, mobile-friendly play sessions.

## Try the game

- [Playable web demo](https://fluffy-forest-bird.eugene-nekrash.chatgpt.site/)
- [Source code](https://github.com/evgeniynekrashseo-sys/bird)

## What's in this repository

- Vanilla JavaScript browser game with responsive interface
- Three difficulty modes: Cozy, Adventure and Expert
- Puzzle generation, level progression, hints, undo and restart
- Animated forest characters, audio/voice assets and localization support
- PWA manifest, Android/iOS build workflows and store-screen asset tooling

## Run locally

No API keys or accounts are needed for the browser build.

```bash
python -m http.server 8000
```

Open http://localhost:8000 and start playing.
